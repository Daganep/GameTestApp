# Требования к приложению «Змейка»

## 1. Описание
Классическая аркадная игра «Змейка» для Android. Змейка перемещается по
квадратному полю, поедает еду, растёт и набирает очки. Смерть наступает при
столкновении со стеной или с собственным телом.

## 2. Функциональные требования

### 2.1 Игровая механика
- F-01. Игровое поле — квадратная сетка 15×15 клеток.
- F-02. Змейка начинается из 3 сегментов в центре поля, движется вправо.
- F-03. Змейка перемещается на одну клетку за тик. Начальный интервал тика — 150 мс.
- F-04. Направление меняется только на 90° (нельзя развернуться на 180°).
- F-05. Еда появляется в случайной свободной клетке; одна еда на поле одновременно.
- F-06. При поедании еды змейка растёт на 1 сегмент, счёт +10.
- F-07. Каждые 5 съеденных единиц еды скорость растёт (интервал тика −10 мс, минимум 60 мс).
- F-08. Столкновение со стеной — конец игры.
- F-09. Столкновение с собственным телом — конец игры.
- F-10. Пауза/продолжение в любой момент игры.

### 2.2 Экраны
- F-11. Экран главного меню: «Играть», «Как играть», отображение рекорда.
- F-12. Экран игры: поле, текущий счёт, скорость, кнопка паузы.
- F-13. Экран «Как играть»: краткие правила.
- F-14. Экран окончания игры: набранный счёт, рекорд (с пометкой «Новый рекорд!»),
       кнопки «Играть снова» и «В меню».

### 2.3 Управление
- F-15. Управление жестом свайпа (верх/низ/влево/вправо) в любом месте экрана.
- F-16. Альтернативное управление — экранные стрелки (D-pad) внизу экрана.

### 2.4 Данные
- F-17. Рекорд (максимальный счёт) сохраняется в локальном хранилище и
        переживает перезапуск приложения.
- F-18. Текущий счёт сбрасывается при новой игре.

## 3. нефункциональные требования
- N-01. Целевая частота кадров — 60 FPS; тик игры не должен дёргать UI.
- N-02. minSdk 24, ориентация — портретная (зафиксирована).
- N-03. Приложение офлайн: никаких сетевых запросов и разрешений.
- N-04. Логика игры (движение, коллизии, рост, спавн еды) — чистый Kotlin,
       без зависимостей от Android, полностью покрыта юнит-тестами.
- N-05. Корректная работа с жизненным циклом: при уходе в фон игра ставится
       на паузу автоматически.
- N-06. Поддержка тёмной темы (Material 3).
- N-07. Размеры элементов поля рассчитываются от ширины экрана
       (поле всегда квадратное и вписывается в ширину с отступами).

## 4. Ограничения и предположения
- Однопользовательская игра, без мультиплеера.
- Без звуковых эффектов (можно добавить позже).
- Без аналитики, рекламы, авторизации.
- Не используются сторонние игровые движки (Unity/libGDX) — только Compose.

## 5. Критерии приёмки
- [ ] Можно начать игру из меню, играть свайпом и D-pad, поставить на паузу.
- [ ] Счёт растёт, скорость ускоряется, рекорд сохраняется между запусками.
- [ ] Столкновение со стеной/телом ведёт на экран «Игра окончена» со счётом.
- [ ] `./gradlew test` — все юнит-тесты ядра проходят.
- [ ] Приложение работает без ошибок на устройстве с Android 7.0 (API 24).
