# Git Publish — добавить файлы, проверить, коммит, пуш

Скилл выполняет полный цикл публикации изменений в Git:

1. **Добавление новых файлов в VCS** — стейджинг новых, изменённых и удалённых файлов (`git add -A`).
2. **Проверка на критические ошибки** — запуск сборки Gradle. Если сборка падает — скрипт **не коммитит** и останавливается с ошибкой.
3. **Коммит** — фиксация с понятным сообщением (сообщение пишется в UTF-8 файл, русский текст не искажается).
4. **Push** — отправка текущей ветки в `origin`.

## Когда использовать
- Только по запросу.

## Как использовать
Скрипт сам находит корень репозитория (работает из любой директории):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .clinerules/skills/git-publish/scripts/publish.ps1 -Message "feat: ..."
```

### Параметры

| Параметр | Описание |
|---|---|
| `-Message` | Сообщение коммита. Если не задано — сгенерируется нейтральное |
| `-WithTests` | Включить в проверку юнит-тесты (`:app:testDebugUnitTest`) |
| `-Task` | Своя Gradle-задача для проверки (заменяет дефолтную), напр. `:app:lintDebug` |
| `-SkipCheck` | Пропустить проверку сборки (не рекомендуется) |
| `-NoPush` | Только коммит без пуша |

### Примеры

```powershell
# Полный цикл: добавить файлы -> проверка сборки -> коммит -> пуш
.\.clinerules\skills\git-publish\scripts\publish.ps1 -Message "feat: логика игры змейка"

# С прогонкой юнит-тестов
.\.clinerules\skills\git-publish\scripts\publish.ps1 -Message "fix: детекция столкновений" -WithTests

# Коммит без пуша
.\.clinerules\skills\git-publish\scripts\publish.ps1 -Message "wip: стадия 1" -NoPush
```

## Правила сообщения коммита
- Формат: `<type>: <описание>`, где type = `feat | fix | docs | chore | refactor | test`.
- Описание — то, что изменилось по существу (на русском или английском, как просил пользователь).
- Всегда передавать `-Message` явно; автогенерация — только запасной вариант.

## Поведение при ошибках
- **Сборка упала** → скрипт останавливается **до** коммита, рабочий код не тронут. Предложить исправление ошибок.
- **Нечего коммитить** → выход с кодом 0, пустой коммит не создаётся.
- **Пуш упал** (нет сети и т.п.) → коммит остаётся локальным; достаточно повторить `git push`.

## Замечания
- Код выхода: `0` — успех, `1` — ошибка (удобно для автоматизации).
- Дефолтная проверка: `:app:assembleDebug` (контрольная компиляция). Юнит-тесты — по флагу `-WithTests`.
- Скрипт намеренно на английском (ASCII), чтобы работать одинаково в Windows PowerShell 5.1 и pwsh без проблем кодировок; русские сообщения коммита передаются через UTF-8 файл (`git commit -F`).
